# Netflix India Landing Page Clone 🎬

A fully responsive frontend UI clone of the Netflix India landing page, built as a first-year diploma student project to master core web development concepts.

## ✨ Features
* **Responsive Design:** Built using CSS Grid, Flexbox, and Media Queries to adapt seamlessly across mobile phones, tablets, and desktop screens.
* **Interactive FAQ Accordion:** Custom JavaScript accordion that smoothly expands/collapses answers and rotates indicator icons.
* **Dynamic Movie Modals:** Clicking any movie card in the Trending Now section opens a detailed Netflix-style overlay card with descriptions, release years, age ratings, and genre tags.
* **Modern UI Elements:** Custom SVG assets, radial gradient background curves, and clean hover animations.

## 🛠️ Built With
* **HTML5** (Semantic markup, meta tags, and responsive viewport configuration)
* **CSS3** (Flexbox, CSS Grid, animations, and custom gradients)
* **JavaScript** (DOM manipulation and event listeners)
